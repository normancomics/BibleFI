# Superfluid Wallet

The maintained [Superfluid Wallet skill](https://app.superfluidwallet.com/SKILL.md) is the source of truth for wallet setup and supported actions. Fetch and follow it when helping with this integration. The [official wallet start page](https://www.superfluidwallet.com/start) is an alternate official setup reference.

Do not infer wallet APIs or claim setup, access, or a transaction succeeded without verifying it using the official instructions and available tools. If the skill and setup page cannot be retrieved, report the specific access blocker rather than substituting instructions for another wallet or inventing a workflow.
